# Genie Agent 공통 질문

## 기본 질문 5개

1. 전체 기간 순매출은 얼마야?
2. 매장별 매출을 높은 순서로 알려줘.
3. 판매수량 기준 TOP 3 메뉴는?
4. 날짜별 매출 추이를 보여줘.
5. 강남점 객단가는 얼마야?

## 분석형 질문 5개

1. 시간대별 순매출과 주문수를 비교하고 피크타임을 알려줘.
2. 주말과 평일의 순매출과 객단가를 비교해줘.
3. 매장별로 가장 많이 팔린 상품을 판매수량 기준으로 알려줘.
4. 카테고리별 할인액과 할인 후 순매출을 비교해줘.
5. 최근 7일의 일별 매출 추이와 가장 높은 날짜를 알려줘.

## 다의어 확인 질문 3개

1. 인기메뉴가 뭐야?
2. 라떼 매출 알려줘.
3. 손님이 가장 많은 매장은 어디야?

위 3개는 바로 SQL을 실행하지 않고 Genie가 기준 또는 대체 지표를 되묻는지 확인한다.
